# SDK 0.3.1 nonce-zero Platform pin

## Context

The isolated Stacks testnet payer flow exposed that SDK 0.3.0 rejected canonical account nonce
`0`, even though a fresh Stacks account legitimately begins at nonce zero. The SDK fix was reviewed
and merged in PR #13, released as `@perkos/agent-sdk@0.3.1`, and validated from a clean registry
installation before this Platform change.

## Change boundary

Platform 0.4.2 pins the exact public SDK 0.3.1 release and updates the verifier evidence recorded
with a settlement. The verifier checksum remains the SHA-256 digest of the exact npm integrity
string. Service discovery reports Platform 0.4.2.

No contract, database schema, merchant policy, quote price, transaction fee, settlement state
machine, feature flag, or production routing changes in this release. Production remains
quote-only; verification, settlement, reconciliation, delivery, and sponsorship stay disabled.
